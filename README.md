# BrewBear Feedback

This repository is to collect feedback, feature requests, bugs, and questions for the **BrewBear** app.

## How to Contribute

- **Feedback**: Share your general thoughts and suggestions about the app.
- **Feature Requests**: Propose new features or improvements you'd like to see.
- **Bug Reports**: Report any issues or unexpected behavior you encounter.
- **Questions**: Ask anything related to the app's usage or functionality.

Please open an issue in this repository to submit any of the above, and apply the appropriate label listed below.

## Labels

| Category | Label |
|----------|-------|
| Feedback | `feedback` |
| Feature Requests | `feature-request` |
| Bug Reports | `bug` |
| Questions | `question` |
